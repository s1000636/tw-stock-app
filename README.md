# 台股券商風格手機模擬 App

這是獨立設計的台股模擬交易展示介面，並非真實券商服務。行情及交易為示範資料。

## GitHub Pages 部署
1. 在 GitHub 建立公開 repository，名稱可用 `tw-stock-app`。
2. 上傳此資料夾中的 `index.html` 到 repository 根目錄（不要放在子資料夾）。
3. 進入 Settings → Pages → Build and deployment，Source 選 `Deploy from a branch`。
4. Branch 選 `main`、資料夾選 `/(root)`，按 Save。
5. 等候部署完成，開啟 `https://你的帳號.github.io/tw-stock-app/`。

## 使用說明
用 iPhone Safari 開啟 GitHub Pages 網址。按下方「下單」進行模擬交易；不會送出真實委託。

## 注意
GitHub Pages 公開站點的原始碼與靜態資源可能被任何人查看。請勿放入真實帳號、密碼、身分證字號或 API 金鑰。
